## Purpose

This repository converts public website content and approved internal engineering knowledge into a consistent, traceable, AI-ready knowledge base.

It is intended to support:

- product and application reference;
- engineering and sales support;
- installation and maintenance guidance;
- standards and material cross-reference;
- internal training;
- AI search, retrieval-augmented generation (RAG), and technical assistants.

## Languages

Primary technical records may be written in Thai, English, or bilingually. File names use English `kebab-case` for stable links and AI ingestion.

## Content status system

Each technical page should declare one of these states:

| Status | Meaning |
|---|---|
| `verified` | Checked against an approved drawing, specification, standard, or current company source |
| `reviewed` | Technically reviewed, but supporting controlled documents may still be incomplete |
| `draft` | Working content; not for quotation, fabrication, or contractual use |
| `archived` | Retained for history; not current |

## Repository status

The initial structure is based on publicly available company website content and product-category information. Dimensions, materials, pressure ratings, leakage limits, test requirements, and standards must be confirmed against current approved documents before commercial or engineering use.

## Important notice

This repository is an information and knowledge-management resource. It does not replace approved drawings, purchase specifications, project requirements, certified standards, inspection records, or formal engineering calculations.
