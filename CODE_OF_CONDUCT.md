# Code of conduct

Contributors must communicate professionally, discuss evidence rather than people,
respect confidentiality and intellectual property, and avoid discriminatory,
threatening, or harassing behavior.

Technical disagreement is expected. State assumptions, cite evidence, and invite
review. Repository maintainers may edit, hide, or reject contributions that expose
sensitive information, misrepresent verification status, or violate these
expectations.

Report conduct concerns privately to the repository owner through a verified
contact channel.
