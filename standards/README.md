# Standards Register

This directory records standards referenced by company products or engineering work. It does **not** reproduce copyrighted standards.

## Publicly referenced standards

| Standard | Related product | Repository note |
|---|---|---|
| AWWA C501 | Cast-iron sluice gate | Verify project edition and scope |

| TIS 383-2529 | Galvanized fabricated flap valve | Verify current applicability and project requirements |

## Required fields for every standard record

- Full designation and title
- Publisher
- Edition/year used by the project
- Product or process scope
- Company document(s) implementing it
- Key controlled requirements as an original summary
- Exceptions, deviations, and client-specific requirements
- Verification owner and review date
