# Security policy

Do not open a public issue containing credentials, personal data, customer
documents, confidential drawings, pricing, or security-sensitive details.

For a security or confidential-data concern, contact the repository owner privately
through the verified organization contact channel. Include the affected path,
impact, and safe reproduction details. Do not attach confidential source files
until a secure transfer method is agreed.

Public factual corrections that contain no sensitive information may use the
content-correction issue template.
