# Public Source Register

Accessed: **2026-07-30**

## Evidence classes

| Class | Meaning |
|---|---|
| `official-public` | Published on the company website or by a responsible public authority |
| `external-primary` | Published by a university, journal, government body, or standards/certification owner |
| `external-secondary` | Search index or business directory used only for corroboration and discovery |
| `controlled-internal` | Approved company document; not present in this public repository unless publication is authorized |

Public evidence establishes what a source states. It does not automatically establish current contractual compliance.

## Source-control rules

1. Search results are discovery aids, not engineering approval.
2. Record the exact source URL and access date.
3. Use current certificate and standard editions for each project.
4. Do not reproduce copyrighted standards.
5. Do not mark numeric product data `verified` without controlled evidence and a named reviewer.
6. If public sources conflict, retain both claims, mark the conflict, and escalate to the document owner.
