## Selection by function

| Function | Typical products |
|---|---|
| Isolate or regulate flow in pipelines | Butterfly Valve, Gate Valve, Knife Gate |
| Prevent reverse flow | Check Valve, Butterfly Check Valve, Flap Valve |
| Release or admit air | Air Valve |
| Control open-channel or wall openings | Sluice Gate, Weir Gate, Stop Log |
| Protect pumps and pipelines | Strainers, Foot Valves, Bell Mouths |
| Connect or transition pipes | Elbows, Tees, Tapers, Sleeves, Couplings, Flanges |
| Support or access equipment | Pipe Supports, Surface Boxes, Wall Thimbles |

## Product record requirements

Every product file must state:

1. Function and intended application
2. Available construction or material options
3. Installation orientation and interface
4. Operating direction and seating condition
5. Referenced standard, where applicable
6. Size and pressure range only when verified
7. Testing and inspection requirements
8. Maintenance points
9. Source URL, access date, evidence level, and revision status

See [`templates/product-template.md`](../templates/product-template.md).

The machine-readable index is [`data/products.csv`](../data/products.csv).
