# Sluice Gate — ประตูน้ำบานเลื่อน

## Function

A vertically moving gate used to isolate or regulate flow through wall openings, channels, chambers, reservoirs, pumping stations, and treatment structures.

## Public website data

| Field | Website claim | Repository status |
|---|---|---|
| Public size range | 150–3000 mm | `draft`; opening geometry and limits not fully defined |
| Standards referenced | AWWA C501, C560, C561; BS 7775 | `website_reference` |
| Cast-iron construction | Product page states manufacture to AWWA C560:2000 | Historical edition claim; verify project edition |
| Operators | Manual gearbox/hoist, electric, pneumatic, hydraulic | `website_reference` |
| Stem forms | Rising and non-rising | `website_reference` |

The page publishes an example leakage calculation attributed to AWWA C560:2000. Because leakage criteria are safety- and contract-sensitive and standard editions can change, the value is not reproduced here as a verified requirement. Use the controlled standard, approved drawing, and project specification.

## Required project inputs

- Clear opening width × height
- Maximum water level and differential head on each side
- Seating and off-seating conditions
- Wall, channel, embedded, or surface mounting
- Operating-floor elevation and stem length
- Number and spacing of stem guides
- Operator type, duty, and required torque/thrust
- Material, seal, fastener, coating, and corrosion environment
- Leakage acceptance and witnessed test method

## Public manual themes

The public Sluice Gate manual covers identification, handling, storage, installation alignment, operation, maintenance records, troubleshooting, and replacement of wearing parts. It emphasizes protecting the gate during handling and maintaining alignment between the frame, disc, stem, and operator.
