# Engineering Terminology

| English | Thai | Meaning |
|---|---|---|
| Butterfly Valve | ประตูน้ำลิ้นปีกผีเสื้อ | Quarter-turn pipeline valve using a rotating disc |
| Gate Valve | ประตูน้ำลิ้นยก | Linear isolation valve using a gate closure |
| Sluice Gate / Slide Gate | ประตูน้ำบานเลื่อน | Gate controlling flow through a wall opening or channel |
| Flap Valve / Flap Gate | ประตูระบายน้ำ / ประตูกันน้ำย้อน | Passive hinged non-return gate |
| Air Valve | ประตูระบายอากาศ | Valve for releasing and/or admitting pipeline air |
| Pipe Support | ตุ๊กตารับท่อ | Structural component supporting or restraining pipe |
| Surface Box | หีบกุญแจ | Access enclosure for operating a buried valve |
| Seating Head | แรงดันด้านกดเข้าบ่า | Head pushing a gate toward its seat/frame |
| Off-seating Head | แรงดันด้านดันออกจากบ่า | Head pushing a gate away from its seat/frame |
